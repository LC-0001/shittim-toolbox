一个《蔚蓝档案》风格的什亭之匣工具箱。阿罗娜与普拉娜坐镇「什亭之匣」，把常用工具收进一个单文件页面——网页打开就能用，也可以装成 Android 应用离线使用。

## 下载

| 版本 | 大小 | 说明 |
| --- | --- | --- |
| **Android APK** | 约 940 KB | [ShittimToolbox-2.7.0.apk](ShittimToolbox-2.7.0.apk) · 支持 Android 7.0 及以上 |
| **网页版** | — | [在线访问](https://lc-0001.github.io/shittim-toolbox/) · 无需安装 |

> Android 版和网页版是同一份页面（v2.7.0）。APK 把页面打包在本地，装好后完全离线，数据只存在自己手机里。

### 安装方法
1. 点开上面的 APK 链接，在页面里点「Download」下载
2. 在手机上打开下载好的文件，如果提示「禁止安装未知应用」，按提示允许即可
3. 装好后桌面图标是戴墨镜的阿罗娜与普拉娜，应用名「什亭之匣」

## 特色
- **蔚蓝档案风格界面**：液态玻璃拟态设计，配合阿罗娜、普拉娜的对话与提示，像在什亭之匣的终端里操作
- **MomoTalk 主题**：一键切换粉色的 MomoTalk 风格，和默认的蓝色主题可以随时切换
- **浅色 / 深色模式**：可手动切换，也可以跟随系统
- **自定义背景**：上传图片作为背景，支持裁剪
- **数据备份与恢复**：设置、对话和主题可以导出为 JSON 文件，换设备时再导入
- **离线可用**：网页版断网也能打开；Android 版整个页面随 APK 打包，不依赖网络

## 功能
- 集成多种实用工具：编码转换、进制转换、字数统计、JSON 格式化、文本对比、URL 解析、时间戳、颜色转换、图片转 Base64、ZIP 解压、图片压缩、UUID、随机密码等
- 单文件运行，无需复杂部署
- 全部数据保存在本地，不会上传到服务器

## Android 版
APK 是一个 WebView 外壳，页面资源和外壳一起打包，所以体积很小、完全离线。

- **版本号**：应用版本 `2.7.0`，对应网页 `v2.7.0`；页脚会显示 `· App 2.7.0` 方便核对
- **下载类功能**：导出备份、解压 ZIP、压缩图片这些原本「下载到浏览器」的操作，改为直接存进系统「下载」目录
- **文件选择**：选择本地图片 / ZIP 走系统文件选择器
- **系统返回键**：先关闭当前面板或对话，再按一次才退出应用
- **主题跟随**：跟随系统深色模式，状态栏颜色随页面主题变化

## 技术栈
网页端是纯原生 HTML / CSS / JavaScript 单文件应用，无框架，无需构建步骤。

Android 版使用原生 WebView 加载内置页面，通过一个轻量的 JS Bridge 提供版本号读取、文件保存和主题色同步，不引入任何第三方 Android 依赖。

## 部署
网页版仅依赖静态资源，支持 GitHub Pages、Vercel、Netlify 等任意静态托管平台。

### GitHub Pages 部署步骤
1. Fork 本仓库到自己的账号
2. 进入仓库 Settings → Pages
3. Source 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存
4. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/shittim-toolbox/`

## 本地开发
本项目为单文件静态页面，无依赖，无需安装任何包。如果你想在自己的电脑上修改和预览，需要先安装 [Python 3](https://www.python.org/)，然后在终端中运行：

```bash
git clone https://github.com/LC-0001/shittim-toolbox.git
cd shittim-toolbox
python3 -m http.server 8000
```

运行后，在浏览器中打开 `http://localhost:8000` 即可预览。这个地址只能在你自己的电脑上访问，关闭终端后服务会停止。
